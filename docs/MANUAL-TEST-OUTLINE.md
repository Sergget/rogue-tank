## 测试清单

### 1. 自身模块/成员受损状态条（#A5）

**入口**：正式游戏页 → 进入任意战斗节点。

**步骤**：
1. 正常移动/开火，观察屏幕**顶部中央**是否出现（无受伤时应为空白/隐藏）。
2. 故意挨打，让敌人命中你的车体（瞄准车体正面多挨几发）。
3. 观察顶部中央是否开始冒出**黄色 ⚠ 胶囊状标签**（如「炮手」「装填手」「引擎」「弹药架」「炮闩」「履带」等）。

**验收**：
- [ ] 无受伤时顶部中央**不显示**状态条（或显示空）。
- [ ] 受伤后出现对应模块/成员的 ⚠ 标签，且文字与受损部位一致（如被击中炮塔→「炮手」/「装填手」，被击中车尾→「引擎」）。
- [ ] 履带断裂时应出现「履带」标签（配合移动受限）。
- [ ] 症状消失（debuff 计时结束）后对应标签**消失**，全部消失后整条隐藏。
- [ ] 标签不遮挡 HUD 关键信息（血量/弹药/小地图）。

### 3. 卡牌平衡（P-42 审计结论抽查）

**入口**：正式游戏 → 结算奖励阶段选卡。

**说明**：审计已确认**数值无红级失衡**，唯一内容缺口是 **HEAT（高爆反坦克）弹种仅 3 张卡、无 epic/legendary 档**（内容补卡属前置，暂缓）。人工只需抽查手感：

- [ ] 抽取常见的 `common`/`rare` 伤害/穿透卡后，战局节奏无明显「一张卡碾压全场」或「拿了等于没拿」。
- [ ] `heat_*` / `he_*` / `demo_*` 三系弹种卡（若抽到）切换后，实际弹道/伤害有**可感知差异**，非仅数值面板变化。
- [ ] 上一条若发现某张卡明显失衡（过强/过弱），记下卡名与现象，回填 ISSUES（勿直接改数值）。

### 4. 地形占位冲突（#A11，本轮未修，仅评估严重度）

**入口**：正式游戏 → 连续开多局，留意 `urban_block` / `crossfire_plaza` / `village_center` 三个模板节点（城镇/广场/村庄）。

**说明**：本期已实证「道路/水域与建筑/林地任意叠加 + 道路不贯穿」**无法安全增量修复**（任何小改都会击穿连通性地板），需地图级路网重构专轮。本轮人工测试目的是**评估这个缺陷在实际游玩中的严重度**，为是否优先排专轮提供依据。

**步骤**：
1. 在城镇/广场/村庄节点，观察道路是否与建筑/树/水域**叠在一起**（视觉穿模、或坦克在「路上」却撞到看不见的障碍）。
2. 观察道路是否**断裂**（走到一半路没了，变成空地但无连接）。

**验收（记录现象，不要求修）**：
- [ ] 压物重叠：□ 经常 / □ 偶尔 / □ 未见
- [ ] 道路断裂：□ 经常 / □ 偶尔 / □ 未见
- [ ] 是否出现**坦克被卡住/无法通过**（比视觉穿模更严重）：□ 是 / □ 否
- [ ] 主观判断严重度：□ 高（影响游玩）/ □ 中（影响观感）/ □ 低（可接受）
