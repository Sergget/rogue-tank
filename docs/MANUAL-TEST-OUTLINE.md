## 测试清单

### 1. 成员/模块受损状态条与修理/医疗门控（#A5, P-49）

**入口**：正式游戏页 → 进入任意战斗节点。

**步骤**：
1. 正常移动/开火，观察屏幕**顶部中央**是否出现（无受伤时应为空白/隐藏）。
2. 故意挨打，让敌人击中炮塔不同象限与车体不同区段。
3. 观察顶部中央是否冒出**黄色 ⚠ 胶囊状标签**：
   - 炮塔正面左区：`炮手`、`炮栓`
   - 炮塔正面右区：`车长`、`装填手`、`炮栓`
   - 炮塔后区/车体中部：`弹药架`
   - 车体尾部（前置炮塔）：`引擎`
   - 履带部位：`履带`
4. 当出现 `炮栓` 损坏时，尝试点击开火，验证是否**短时间内完全无法开火**。
5. 观察主动技能（医疗包/修理箱）：
   - 当成员/模块无损伤时，对应技能是否为**置灰/门控禁止误用**状态；
   - 出现对应受损后，释放技能是否能立刻清除 debuff 并使顶部状态胶囊同步消失。

**验收**：
- [ ] 无受伤时顶部中央不显示状态条。
- [ ] 受伤后出现对应部位 ⚠ 标签且文字准确。
- [ ] 炮栓受损时无法开火，debuff 结束后恢复正常。
- [ ] 医疗包/修理箱在无伤时禁止触发，受损释放后即时清空 debuff 与 HUD 胶囊。
- [ ] 标签不遮挡血量、装填条与弹药切换等核心 HUD。

### 2. 类别化敌军与多向环带压制感（P-46）

**入口**：正式游戏页 → 连续进行 2~3 个战斗节点。

**步骤**：
1. 观察开局敌军生成方位：是否呈现**围绕玩家的多方向环带分布**（2~4 向，不再是单纯右侧聚簇）。
2. 观察不同车型敌人的 AI 战术行为：
   - **轻型车**（高机动）：是否主动侧绕（Flank）寻找侧后破绽；
   - **重型车**（低速重甲）：是否只进不退正面逼近并具备抗晕感；
   - **SPG**（如 Hummel）：是否主动退后保持安全射程（Keep Range）。
3. 验证第一关敌军属性是否与玩家当前出战车型的战斗力基准自然对齐（无瞬间秒杀或完全不破防的荒谬数值）。

**验收**：
- [ ] 敌军刷新点呈多向分布，形成包围/压制走位空间。
- [ ] 轻/重/SPG 三类车型 AI 走位风格有肉眼可辨的差异。
- [ ] 战局节奏自然，无玩家怪兽车碾压或初始数值失衡。

### 3. 坦克对比器与单位标定（P-48）

**入口**：打开 `http://127.0.0.1:8000/tank_compare.html`。

**步骤**：
1. 观察对比器参数列表是否分为**火力 (Firepower)、防护 (Armor)、机动 (Mobility)、杂项 (Misc)** 四个清晰大类。
2. 检查数值设定与单位回显：
   - 极速：是否直接以 **km/h** 输入与显示；
   - 炮管长度：是否直接以 **m**（米）输入与显示；
   - 精度：是否以 **100m 散布(m)** 单一综合指标输入与显示（不再是抽象乘数）。
3. 检查功重比（hp/t）与派生重量是否在机动分组尾部正确计算联动。

**验收**：
- [ ] 四大分组布局清晰、带分类图标，无旧版「真实单位标定」冗余栏目。
- [ ] km/h、m、100m 散布换算数值准确，无 NaN 或未定义错误。

### 4. 坦克设计器属性耦合与重量上限（P-49）

**入口**：打开 `http://127.0.0.1:8000/tank_designer.html`。

**步骤**：
1. 调整装甲厚度、炮管长度、穿深与单发伤害。
2. 观察面板上的**属性耦合联动提示**：
   - 增加穿深/伤害是否导致基础装填时间与散布惩罚上升；
   - 增大车体长宽是否使车体面积易损因子（0.7x~1.3x）与最大可用马力联动变化；
   - 重量（派生重量）是否随装甲几何自动计算。
3. 尝试将各装甲板拉到极端最大值，观察是否在达到 **80t 设计上限** 时给出限制/阻止继续增重。

**验收**：
- [ ] 模块可视化挂载已移除，转为纯几何装甲编辑。
- [ ] 穿深/伤害对装填惩罚、车体面积对易损因子的回显实时响应。
- [ ] 80t 设计上限限制生效。
