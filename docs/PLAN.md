# Rogue Tank — 规划重构路线 (PLAN.md)

> 本文档记录新方向 `feature/rogue-tank-rework` 分支下的执行规划。

---

## 阶段一：核心架构转型与武器解耦 (R-1)
1. **主副武器系统扩展**：在坦克 JSON 与 `tank_model.js` 中引入主武器/副武器双槽位定义。
2. **主动技能树与模组槽位**：实现“超级火控”、“超级速度”等主动技能基础框架与 HUD 冷却条。
3. **视觉热重载机制**：为实体添加 `_visualVersion` 与脏标记刷新管线，支持战斗中炮塔/炮管附件动态变形。

## 阶段二：召唤物与战术部署 (R-2)
1. **固定炮塔与地雷系统**：利用 `entities` 注册表实现零移速固定炮塔及触发式地雷。
2. **无人机扩展**：完善侦察、察打一体无人机的指挥带宽与指令交互。
3. **战术护盾/掩体部署**：实现动态生成可被物理推动、具备耐久与护盾吸收的掩体实体。

## 阶段三：曲射武器与特种弹药 (R-3)
1. **迫击炮与曲射物理**：实现具有弹道弧度（`arc`）与观测校射加成的曲射机制。
2. **APFSDS 与特种弹**：实装高初速低衰减穿甲弹及特种效果弹。
