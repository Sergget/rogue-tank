## 为什么这里不是逐字转载

本文件原本计划内联 259 行原文。实测该路径在沙箱下**只允许创建、不允许二次写入**（`write` 可建文件，但随后任何 append / 覆盖 / 删除均被拒：PowerShell、`cmd`、`.NET File.Open`、`node fs` 全部返回 `EPERM` / `Access denied`）。因此改用**等价且更可靠**的留存方式：

1. **原文在 git 对象库里逐字保存**——拆分前的 `docs/specs/boss.md` 已随提交 **`57be2ca`**（`docs(specs): 五卷主题化重构 —— 卷首主题索引 + 数值去重 + 实质错误修正（编号零变更）`）入库。
2. **可随时还原**（在仓库根目录执行）：

```bash
# 查看原文
git show 57be2ca:docs/specs/boss.md | less

# 还原成文件（另存，不覆盖兼容索引页）
git show 57be2ca:docs/specs/boss.md > /tmp/boss-pre-wiki.md
```

3. 下方给出**分节行号清单**，即使不还原全文，也能按节定位到上面的 git 原文里核对任何一段。
