## laser-turn 乘数方案（已废弃）

（原 §7.1 的 ~~删除线~~ 部分，`#G1` 2026-09-21）

> **原文（照录）**：
>
> ~~timed modifier 源 `boss-laser-turn` + `chargeTurretTurnMul`/`fireTurretTurnMul` 乘数~~ **已废弃**：乘数方案在 Boss 基础 `turretTurnRate`（经 tuning ×0.6 与难度乘子压低）上再乘 0.15~0.18，实际角速度 ≈ 0（用户实测「炮塔又不转动了」）。历史上它修复了「蓄能期每帧叠加同源修饰器被加法聚合钳到 0、射击期恢复全速甩头」的问题，但最终被更稳的固定角速度直驱取代。

**现行口径**：`updateBossLaser` 直接推进 `t.turretAngle`，角速度 = `RULES.boss.laser.laserTurnSpeed`（**0.35 rad/s**，#I1 由 0.55 再降），固定绝对值、不受 modifier/难度影响 → 见 [蓄能激光 · 炮塔转速](./laser.md#炮塔转速固定角速度直驱)。

> **教训**：这是一个「用乘数修乘数」的叠加陷阱——基础角速度已被 tuning ×0.6 与难度乘子压低，再乘 0.15 就趋近于 0。**绝对角速度直驱**比乘数链更可预测。

## 电磁炮炮线的首版绘制与声学（2026-10-22，已被 2026-10-26 取代）

（原 [电磁炮的炮线与预警](./railgun.md) 「绘制契约」与 #AA-c Boss 侧声学接线，2026-10-26 按用户反馈改口径）

> **原文（照录）**：
>
> - **charge**：白色 1px 主线（alpha `0.25 + 0.5×progress`）+ 沿主线 3 条 `lightningPath` 电弧（锯齿幅度 `4+6×progress`）+ 线端白光点（半径 `6+6×progress`，外圈冷白晕）+ 线两侧淡红晕（`rgba(255,80,60,0.10)`）。
> - **fire**：白芯 `max(2, width×0.5)` + 冷白外晕 `width×1.6`，按 `fx.alpha` 淡出。
> - **配色**：三档取自 `RULES.railgunFx`（`barrelGrey / base / arc`），不写死颜色。
> - **玩家预警**：进入蓄能时 `pushLog(...)` + **音效**；屏幕顶部红色横条（2.4s）。
> - **Boss 侧声学**（#AA-c 2026-10-26）：`railCharge` 驱动充能循环音高，`railReady` 收声 + 就绪提示。

**取代原因**（用户 2026-10-26 原话）：「boss使用电磁炮时：音量太大、激光应该是红色不动的指示性激光（不是现在的常用于攻击性的不断抖动的）、玩家被电磁炮激光指向时不需要有音效，电磁炮发射炮弹的音效像射箭而不是发射了电磁炮」。

- 白芯 + 蓝基底 + 时间量子抖动的电弧读作**放电攻击特效**，不是瞄准指示 ⇒ 改为红色恒定指示线（细红实线 + 红外晕 + 固定半径落点圆点，零电弧零抖动）。
- 指向期的循环电流声 / 就绪双响 / 预警 `ui` 音**全部静音**（`RULES.boss.railgun.aimAudio = false`），只留屏幕预警。
- 开火瞬态由 `firerail`（三层电磁炮声学）改为 `bossRailFire`（弓弦 + 破空，gain 0.55）——「像放箭」；玩家侧仍 `firerail`。

**现行口径**：[电磁炮的炮线与预警](./railgun.md)（参数表 / 绘制契约 / 音频口径）· [音频与音效](../combat/audio.md#boss-电磁炮指向期静音-开火像放箭2026-10-26-用户裁定)。
