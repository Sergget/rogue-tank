# 友军指挥与战术协同

> **摘要**：单机少量 AI 友军的三命令（跟随/移动/集火）、目标权威与状态反馈；A0 已落地。
> **适用版本**：A0 三命令已落地（2026-10-27）；A1/A2 设计预留
> **源自**：2026-10-26 用户裁定「多人合作暂不考虑，少量友军和友军命令系统」；`docs/specs/combat.md` §16（新建）
> **相关**：[敌方 AI](./enemy-ai.md) · [HUD 与界面](./hud-ui.md) · [渲染路线](../map/rendering-roadmap.md) · [浏览器测试链](../editor/browser-tests.md)

| 子项 | 状态 | 说明 |
|---|---|---|
| 单机与少量友军方向 | **已裁定** | 不做本地/在线多人；首个切片设计容量为 2～4 辆友军，最终数量由战斗与性能实测决定 |
| 三命令与指挥 UX | **A0 已落地** | `follow / move / focus` + **Z/X/C 直接快捷键**（命令转盘暂时关闭）；单车命令与手柄动作层未做（A2） |
| 目标与任务协调 | **A0 已落地** | 新增纯逻辑任务层 `js/tank_ally_command.js`；决策与击发读同一权威目标 |
| 职能、导航与协同构筑 | **设计预留** | 在命令闭环后分批实施，不以增加人数替代行为质量 |

## 1. 目标与现状边界

目标是在**不中断玩家驾驶、瞄准与开火**的前提下，让少量友军执行可理解的战术意图。参考即时战术命令的「指目标、给意图、看反馈」，不把车战变成逐车 RTS 微操。

2026-10-26 实测边界：

- `tank_battle.html` 的非玩家实体统一经 `aiDecide` 与 `driveTank`；友军自主索敌，但开火目标仍由 `nearestEnemyTo(e)` 现取（**A0 已改为 `allyFireTargetFor`，见 §5.1**）。因此仅在 AI 输出里加目标字段不足以实现集火，**决策与击发必须读同一个权威目标**。
- `js/tank_ai_squad.js` 的 `updateSquad` 只向 `enemies` 分配 `press/flank/hold`，是敌军协调器，不是友军命令系统。
- 现有友军可复用实体、武器、伤害、AI 和节点流程；本设计不另造友军伤害/命中规则，不引入网络同步。

## 2. 首版三命令（2026-10-27 用户裁定简化）

> **沿革**：2026-10-26 首版设计为六命令（focus / move / follow / hold / retreat / flank）。2026-10-27 用户裁定**简化为三命令**——`hold` 并入 `move`（到达即驻守）、`retreat` 并入 `follow`（跟随玩家即回撤）、`flank` 取消。六命令版本从未成为现行口径。

| runtime 命令 | 玩家意图 | 执行语义 | 终止/替换 |
|---|---|---|---|
| `follow` | 跟随玩家 | 保持队形跟随；**在可攻击目标中随机**选择目标开火 | 任意新命令 |
| `move` | 移动到指定位置 | 前往光标地面并分散占位；**攻击最近的可攻击目标**；到达后原地驻守（命令仍是 move） | 新命令；离开锚点 1.6×半径自动重新推进 |
| `focus` | 集火指定目标 | **不冲向目标**：有锚点时在锚点射击，否则跟随玩家；只射击任务目标，不暗换最近敌人 | 目标死亡 → `blocked/target-lost`；新命令 |

**可攻击目标**：存活敌人、在 `RULES.allyCommand.autoEngageRange` 内、有视线（`hasLoS` 可用时）。

**输入（2026-10-27 用户裁定）**：`Z` = 跟随 / `X` = 移动 / `C` = 集火，目标/位置取当前光标世界点；键位唯一数据源 `js/tank_bindings.js` 的 `commandFollow` / `commandMove` / `commandFocus`。**命令转盘暂时关闭**（`RULES.allyCommand.wheelEnabled = false`，按住 Z 三扇区选择的实现保留，置 true 即恢复）。卡牌查看器因此从 C 改到 `B`。

## 3. 控制层级、任务与优先级

- **控制层级**：A0 先做**全体命令**（转盘一次作用于全部友军）；单车/职能编组属于后续 UX 扩展。
- **任务快照**：每辆友军持有 `{order, issuer, targetId?, anchor?, issuedAt, phase, reason}`；实体死亡/节点切换/读档时按生命周期清理或恢复，禁止跨节点悬挂旧目标。
- **执行优先级**：防即死与防卡死的**局部反射** → 玩家直接命令 → 职能默认行为 → 自主交战。
- **局部反射边界**：允许短程躲爆炸、火焰、致命水域和解堵；不得以低血量、自主找掩体或换目标为由长期取消命令。偏离后须返回任务，确实失败才进入阻塞报告。
- **打带跑**：移动与跟随期间仍按武器射界、装填决定开火；命令不是「只移动」开关。
- **友军非无敌**：伤害、模块、隐蔽、烟幕与地形沿用现有规则；是否允许被玩家复活/修理属于后续经济裁定。

### 3.1 统一目标权威

实施时新增纯逻辑任务/协调层（候选 `js/tank_ally_command.js`，最终命名随模块边界确认），其职责：

1. 把玩家命令解析为不可歧义的任务快照，校验目标存活、敌我、区域与可达性；
2. 为每辆友军分配目标、锚点与阶段，不与敌军 `updateSquad` 共用会串状态的全局缓存；
3. 向 `aiDecide` 注入任务上下文，输出机动与炮塔意图；
4. 向击发入口提供同一个 `targetId`/目标实体，替换友军击发时无条件 `nearestEnemyTo` 的绕行；
5. 在目标死亡、命令替换、节点清理时显式失效，禁止保留悬空实体引用。

**写域**：AI/任务状态与 `RULES` 由 role-systems；武器击发契约如需修改由 role-combat 协调；HUD/命令环由对应页面唯一写者接入。不能三个角色同时改 `tank_battle.html`。

## 4. 输入与反馈

### 4.1 操作

- **Z / X / C 直接下令**：跟随 / 移动 / 集火；目标/位置取按键瞬间的光标世界点。命令转盘实现保留但暂时关闭（`wheelEnabled=false`）。
- 世界内目的地与集火目标标记只在任务存在时显示，避免常驻遮挡战场。
- 首版**不默认战术暂停或慢动作**。若实测驾驶中无法可靠操作，再单独评估轻度减速并补输入/模拟一致性测试。
- 命令输入从动作层抽象，键鼠与手柄共用；不得在 UI 层直接写友军坐标或目标。

### 4.2 可读状态

| 状态 | 玩家必须读到 |
|---|---|
| 已接受 | 谁接受、执行什么；头像/车旁图标 + 简短确认音/语音 |
| 执行中 | 移动、驻守、跟随等阶段；不刷屏、不每帧播语音 |
| 受限 | 无射界、被压制、路径暂堵；区分「仍在尝试」与「已失败」 |
| 失败 | 不可达、目标失效等具体原因，并给可操作的取消/重下指令 |
| 完成 | 到达目的地或完成集结，转入何种后续状态 |

语音承担信息反馈，按「受击/致命危险 > 命令失败 > 接敌 > 常规确认」限流。三命令的默认语义必须在 HUD 可发现，不依赖玩家背文档。

## 5. 职能、导航与构筑扩展

| 工作包 | 边界 |
|---|---|
| 前卫/重甲 | 卡路口与承受压力；仍受玩家移动/跟随命令约束 |
| 侦察/轻甲 | 点灯、标记、侧袭；不得变成永久最优万能车 |
| 火力支援 | 自走炮/导弹依赖射界或友军视野，与现有曲射/锁定契约一致 |
| 保障/工程 | 修理、烟幕、部署掩体，A0 后再裁定资源与冷却 |
| 导航 | 编队间距、窄路让行、替代路径、动态破坏后的重寻路、避水避火与脱离通道 |
| 构筑 | 指挥响应、协同标记、维修/补给、烟幕/交叉火力等；禁止只堆友军血伤 |

遭遇可设计守点、夹击与反伏击来让命令有意义，但**不得让大部分节点退化为护送脆弱 NPC**。友军强度、击杀得分与补给需一起校准，避免抢光成长资源或成为免费消耗品。

## 5.1 A0 落地口径（2026-10-27 简化版）

### 模块与数据

- **唯一逻辑入口**：`js/tank_ally_command.js`（纯逻辑、Node 可测、无 DOM）。
- **任务快照**：每辆友军持有 `_allyOrder = {order, issuer, targetId, anchor, issuedAt, phase, reason}`；`phase ∈ moving / holding / blocked`。
- **目标权威**：`allyFireTargetFor(ally, ctx)`：
  - `focus` 只认任务目标，目标死亡即 `null`——**不暗换最近敌人**；
  - `move` 选**最近**可攻击目标；
  - `follow`（及无任务）在可攻击目标中**随机**选择。
- **决策**：`aiDecide` 对 `team==='ally'` 且有任务时调用 `allyCommandDecide`，输出与 `aiDecideAlly` 同形；随后仍叠加 `applyWaterAvoidance`（友军不为命令豁免地形）。
- **状态机**：`updateAllyOrder` 处理 move 到达 → `holding`、离开 1.6×半径 → 重新 `moving`、focus 目标丢失 → `blocked/target-lost`、长时间无位移 → `blocked/stuck`。
- **转盘选择**：`radialOrderFor(dx, dy, deadZone)` 纯函数（上=follow / 右下=move / 左下=focus）。
- **编队规格**：`allySquadSpecs(node, mode, cfg)` 由 battle 与 `tank_3d.html` 共用。

### 配置（`RULES.allyCommand`）

`enabled` / `maxAllies` / `arriveRadius` / `formationSpacing` / `autoEngageRange` / `stuckSeconds` / `stuckSpeed` / `retargetSeconds` / `aimTolerance` / `countByMode` / `allyTankId`。数量按模式：**standard 2 / survival 2 / boss 1**；标准模式仍保留指挥友军，但**不再预生成「友军据点」**（见 `specs/map/map-architecture.md`）。友军坦克 `panzer-IV`。六命令时代的 `focusBand` / `flankOffset` / `retreatRange` 已删除（简化时清理）。`retargetSeconds`（3s）让自动目标保持，避免 follow 的随机目标逐帧重掷。

### 输入（`js/tank_bindings.js` 唯一数据源）

| 键 | 命令 | 语义 |
|---|---|---|
| `Z` | `follow` | 跟随玩家；随机攻击可攻击目标 |
| `X` | `move` | 前往当前光标世界点；攻击最近可攻击目标 |
| `C` | `focus` | 射击光标处敌人；有锚点时在锚点射击，否则跟随玩家 |

- 目标/位置取**按键瞬间**的光标世界点；`focus` 光标下无敌军时整批拒绝并提示。
- **命令转盘暂时关闭**（`RULES.allyCommand.wheelEnabled = false`）；实现保留，置 true 恢复「按住 Z 三扇区选择」。
- 卡牌查看器由 C 改到 `B`（避免与集火冲突）。

### 反馈与生命周期

- HUD：左下 `#allyHud` 列出每辆友军的命令/阶段；命令接受/拒绝/受阻走 2 秒 `#allyToast` + 日志。
- 世界标记：锚点圆环+十字、集火目标红圈、车顶命令字标（`drawAllyOrderMarkers`）。
- 节点切换时 `clearAllAllyOrders` 并重新生成编队；任务不跨节点悬挂。
- 友军与据点（`outpost_*`）区分：`isAllySquad` 标记，结算加成只认据点。

### 已知边界（A1/A2 处理）

- 敌军 AI 仍只把玩家当主目标，友军暂不承担「被集火」压力。
- 只有全体命令；单车命令、手柄动作层、职能编队与导航让行未做。
- 不做逐车 RTS 微操、战术暂停与多人共享命令。

### 验证

`node scripts/test-ally-command.js`（快照/校验/目标权威/状态机/决策/转盘/编队规格）+ `node scripts/test-browser-ally.cjs`（生成/转盘/集火权威/目标死亡/移动/跟随/HUD）。

## 6. 验收与回归

### 6.1 A0 必过场景

1. **完整战术链**：跟随推进 → 转盘集火非最近目标 → 转盘移动到指定位置 → 轻按跟随；目标选择与击发目标一致。
2. **替换语义**：新命令覆盖旧任务，不叠加；focus 目标死亡 → `blocked/target-lost`。
3. **不可达**：move 锚点在致命水域/地图外时拒绝并提示；不原地抖动、不谎报执行。
4. **射界与自主交战**：`focus` 不暗换最近敌人；`move` 打最近、`follow` 打随机可攻击目标。
5. **防卡死**：多车窄路、玩家堵路、动态残骸后有界时间内脱困或报告；不持续相互推挤。
6. **生命周期**：死亡、节点切换、重开与读档清理任务；存档恢复不产生重复友军或悬空目标。
7. **UX**：Z/X/C 三命令可发现/可取消；失败原因在 2 秒内可读。
8. **性能与确定性**：固定 seed + 命令输入回放可复现目标/伤害/位置；命令评估有节拍预算，不逐车逐帧全图搜索。

### 6.2 测试分层

- 纯 Node：命令转移、目标权威（focus/最近/随机）、优先级、失效条件、转盘角度与不可达。
- 浏览器：转盘按住/扇区选择/松开执行、HUD 状态、驾驶中发令、目标死亡。
- 场景 soak：多 seed、多地形与动态破坏；记录堵路、任务超时和友军输出占比，不能只测「不抛异常」。

## 7. 明确不在首版范围

- 本地/在线多人、网络同步、房间和共享命令；
- 直接驾驶友军、无限友军、复杂队形编辑、逐车技能微操；
- 把敌人 `press/flank/hold` 三角色改名后当作完整指挥系统；
- 通过让友军免疫伤害、必中或无视掩体来掩盖导航与射界缺陷。
