# 战斗与物理系统规范

> **摘要**：本卷是战斗系统的现行口径权威，覆盖弹道、装甲、技能、AI、特效、模式，共 16 个主题页。
> **适用版本**：现行（2026-10-21）
> **源自**：`docs/specs/combat.md` 全卷（含 §0 主题索引；2026-10-21 wiki 化拆分）
> **相关**：[specs 总目录](../README.md) · [风格规范](../../WIKI-STYLE.md) · [兼容索引](../combat.md)

## 从这里开始

- 本卷管：**一次开火到一次命中**的完整链路（弹种 → 装甲 → 模块伤害）、主动技能与副武器、敌方 AI、特效与音频、HUD、部署物、Boss 战斗、游戏模式。
- 本卷不管：**地图/掩体 tier/路网/水域** → [地图规范](../map.md)；**卡池与卡牌效果** → [卡牌规范](../cards.md)；**Boss 数据与血量倍率** → [Boss 规范](../boss.md)。
- 所有数值的最终真值在 `js/tank_rules.js`（`RULES`）与 `js/tank_weapons.js`（`WEAPON_DEFAULTS`）；本卷写「当前值 + 约束 + 易错点」。
- 手上有一个 `§N` 旧引用（如 `combat.md §3.2`）→ 见 [兼容索引](../combat.md)，编号一一对应。
