## 半高掩体时代的作废原文

（原 §3 首条 / §6 水系与岩石裁定 / §12.1 沿革，2026-09-20 #E1/#E3 之前）

- **越掩插值（C 实验）——已作废（2026-09-20 #E3）**：~~射线高度在炮口（medium 1.8m/heavy 2.2m）与目标部位中心间线性插值；攻击方贴近半高掩体（距入口 < 约1/3射程）时射线高于掩体顶（1.4m）→ 越掩 exposure=1.0。~~ 现行拦截模型是确定性的、无任何越掩插值，见 [掩体体系](./cover-system.md)。
- **半高掩体 `half` tier 与 `RULES.heights` 体系**：`RULES.coverTiers.half`、`RULES.heights.cover.half`（1.4m 越掩高度）均已删除；`RULES.heights` 整个体系于 2026-10-19 #9 退役（`js/tank_geometry.js` `getPartZRange` 改按部位直接判定）。代码实测 `RULES.heights === undefined`。
- **`shellBlock: 'grad'` 渐变剖面**：2026-09-20 #E1 起不再是合法取值。旧链三处「不可见拦截」来源（残骸 OBB 过大 / `s.dec` 缓存跨帧失效 / 视野圈外实体拦弹）的原文与处置表见 [掩体体系 · 确定性弹道拦截](./cover-system.md#确定性弹道拦截)。
- **半高墙深描边 `#2e2410`**：随 `half` tier 于 2026-09-20 删除，现行配色以 `RULES.coverTiers` 为唯一口径。

## 水系与桥梁的作废原文

（原 §1 末条 / §6 水系裁定 / §17.3）

- **水体/桥梁（P-20，历史）**：waterBridgeChance = diff×0.5 概率插入；水体不可通行（move:0）、桥梁通道（move:1）；尺寸封顶节点 40%，边界钳制防越界；玩家出生点 findPlayerSpawn 排除水域。**已被 2026-09-14 水系重做取代**：water/river `passability=0.4` 减速通行 + 完全浸入溺毙，现行值见 [河流、水域与溺毙](./rivers.md)。
- **水系与岩石通行性裁定（2026-09-13 复查落地；已被 2026-09-14 水系重做取代）**：~~`RULES.coverTiers.water` 与 `river` 的 `passability` 统一定为 `0.0`（不可通行、实体碰撞推出硬阻断）~~——现行值为减速通行 + 溺毙，见 [河流、水域与溺毙](./rivers.md)。
- **支流缝合（#S1，2026-10-15；已被 2026-10-18 #U34 删除）**：H1T 支流汇入点 y 改用干流实际 segment 采样；支流末端伸入干流内部（过中心线 `thick*0.25`），取消末端收分（原 1.0→0.55）。**支流汇入设计已整体删除**，见 [河道形态与沿程宽度](./rivers.md#河道形态与沿程宽度)。
- **桥梁体系（#U7，2026-10-17 删除）**：`bridge` tier 仍留在 `RULES.coverTiers`（旧存档/基线兼容），但**已不再产出**；`bridge`/`road` 在水域收尾里豁免（桥面与水共存是设计意图）。相关死配置清理见 [死配置清理](./generation-cleanup.md#死配置清理与一处误判纠正)。
