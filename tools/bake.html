M0 贴图烘焙导出工具（P-06 / DEVELOPMENT.md §2.10）

遍历 ASSET_DEFS 每一档，在离屏 canvas 上用程序化 bake 函数烘焙贴图，展示预览并导出 PNG（保存到 assets/ 目录）。

  • 导出文件名 = <key>.png（基底层）与 <key>_canopy.png（树冠/叶片层，仅 bush/tree/fallen）。
  • 用 canvas.toBlob + <a download>，无需服务器——file:// 直开本页即可。
  • 精灵契约：掩体中心位于图片内 (anchorX, anchorY) 像素处（预览中红十字标出实测锚点）；日后真实美术替换同名文件即可，drawAsset 接口不变。
  • 运行期：js/tank_assets.js 的 Image 加载器读到图片 → drawImage；无图/未加载 → 程序化 bake 回退（视觉零变化）。
